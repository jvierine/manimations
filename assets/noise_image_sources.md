# Noise-slide image sources

- `haslam_408mhz.png`: existing project rendering, generated by `make_haslam_map.py`.
- `planck_cmb_esa.jpg`: ESA and the Planck Collaboration, 2013. Temperature anisotropies, not the absolute CMB brightness.
  https://www.esa.int/ESA_Multimedia/Images/2015/09/Planck_CMB
  https://www.esa.int/var/esa/storage/images/esa_multimedia/images/2015/09/planck_cmb/12583930-4-eng-GB/Planck_CMB_pillars.jpg
- `atmospheric_windows_nasa.gif`: NASA Earth Observatory, Remote Sensing. Atmospheric transmission versus wavelength, axis not to scale. The slide highlights the microwave portion without changing the source image.
  https://science.nasa.gov/earth/earth-observatory/remote-sensing/
  https://assets.science.nasa.gov/content/dam/science/esd/eo/content-feature/remotesensing/images/atmos_win.gif
